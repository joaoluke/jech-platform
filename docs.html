📚 Documentação Completa Jech

Bem-vindo à documentação oficial da linguagem de programação Jech! Esta linguagem foi criada com propósito educacional para demonstrar como interpretadores, compiladores e máquinas virtuais funcionam na prática.

Jech é uma linguagem de tipagem dinâmica com sintaxe clara e intuitiva, perfeita para aprender os fundamentos de linguagens de programação e entender como o código é processado desde a análise léxica até a execução.

🚀 Instalação

Existem duas formas de usar Jech:

1. Playground Online (Recomendado para Iniciantes)

A forma mais rápida de começar é usar o playground online. Não requer instalação e roda diretamente no navegador via WebAssembly.

  • ✅ Sem necessidade de instalação
  • ✅ Execução instantânea no navegador
  • ✅ Exemplos prontos para testar
  • ✅ Ideal para aprendizado rápido

2. Instalação Local

Para desenvolvedores que querem explorar o código fonte e entender a implementação:

# Clone o repositório
git clone https://github.com/joaoluke/jech.git
cd jech

# Compile o interpretador
make

# Execute um arquivo .jc
./build/jech examples/01_hello_world.jc

# Ou use o REPL interativo
./build/jech

🎯 Primeiros Passos

Vamos começar com o programa mais simples possível em Jech: o famoso "Hello, World!". 

// Seu primeiro programa Jech!
say("Hello, World!");

Este programa usa o comando say para exibir uma mensagem na tela. Simples assim! Vamos entender cada parte:

  • say - Função nativa que imprime valores na saída
  • "Hello, World!" - Uma string (texto entre aspas duplas)
  • ; - Ponto e vírgula obrigatório no final de cada instrução

💬 Comando say - Exibindo Valores

O comando say é a forma de exibir informações em Jech. Ele aceita diferentes tipos de dados e os imprime na saída padrão.

Imprimindo Strings (Texto)

say("Esta é uma string");
say("Strings podem ter espaços e pontuação!");
say("Até caracteres especiais: @#$%");

Imprimindo Números

// Números inteiros
say(42);
say(0);
say(999);

// Números decimais (floats)
say(3.14);
say(0.5);
say(100.99);

Imprimindo Booleanos

say(true);   // Exibe: true
say(false);  // Exibe: false
Dica: O comando say automaticamente adiciona uma quebra de linha após cada valor impresso. Cada chamada de say imprime em uma nova linha.

📦 Variáveis - Armazenando Dados com keep

Em Jech, usamos a palavra-chave keep para declarar variáveis. O nome "keep" foi escolhido para ser intuitivo: você está "guardando" um valor.

Jech possui tipagem dinâmica, o que significa que você não precisa declarar o tipo da variável - o interpretador descobre automaticamente!

Declarando Variáveis

// Variáveis de string
keep name = "Alice";
keep greeting = "Hello";

// Variáveis numéricas
keep age = 25;
keep score = 100;
keep price = 19.99;

// Variáveis booleanas
keep isActive = true;
keep isComplete = false;

Usando Variáveis

Depois de declarar uma variável, você pode usá-la em qualquer lugar do código:

keep username = "Bob";
say(username);  // Exibe: Bob

keep points = 500;
say(points);     // Exibe: 500

Reatribuição de Variáveis

Você pode mudar o valor de uma variável depois de declará-la. Note que na reatribuição você não usa a palavra keep novamente: 

// Declaração inicial
keep counter = 0;
say(counter);  // Exibe: 0

// Reatribuição (sem keep!)
counter = 1;
say(counter);  // Exibe: 1

counter = 2;
say(counter);  // Exibe: 2
📝 Importante: Todas as declarações e atribuições devem terminar com ponto e vírgula (;). Esquecer o ponto e vírgula causará um erro de sintaxe!

🎨 Tipos de Dados

Jech suporta quatro tipos principais de dados. Vamos explorar cada um em detalhes:

1. Números (Numbers)

Jech trabalha com números inteiros e decimais (ponto flutuante). Não há distinção entre int e float - todos são tratados como números. 

// Números inteiros
keep age = 25;
keep quantity = 100;
keep zero = 0;

// Números decimais
keep price = 19.99;
keep pi = 3.14;
keep half = 0.5;

// Números negativos
keep debt = -50;
keep temperature = -10.5;

2. Strings (Texto)

Strings são sequências de caracteres delimitadas por aspas duplas ("). Elas podem conter letras, números, espaços e caracteres especiais. 

keep greeting = "Olá, Mundo!";
keep name = "Jech";
keep message = "Strings podem ter espaços!";
keep special = "Caracteres especiais: @#$%";
keep empty = "";  // String vazia

3. Booleanos (true/false)

Booleanos representam valores lógicos: verdadeiro (true) ou falso (false). São muito úteis em condicionais e controle de fluxo. 

keep isOnline = true;
keep hasPermission = false;
keep isLoggedIn = true;
keep debugMode = false;

4. Arrays (Listas)

Arrays são coleções ordenadas de valores. Podem conter números, strings ou valores mistos. 

// Array de números
keep numbers = [1, 2, 3, 4, 5];

// Array de strings
keep names = ["Ana", "Bruno", "Carlos"];

// Array vazio
keep empty = [];

// Array misto (diferentes tipos)
keep mixed = [1, "texto", true, 3.14];

🔢 Operadores Aritméticos

Jech suporta as quatro operações matemáticas básicas. Você pode usar operadores diretamente em expressões ou modificar variáveis existentes.

Adição (+)

keep sum = 5 + 3;
say(sum);  // Exibe: 8

// Incrementando uma variável
keep total = 100;
total = total + 50;
say(total);  // Exibe: 150

Subtração (-)

keep difference = 20 - 8;
say(difference);  // Exibe: 12

// Decrementando uma variável
keep balance = 1000;
balance = balance - 250;
say(balance);  // Exibe: 750

Multiplicação (*)

keep product = 4 * 5;
say(product);  // Exibe: 20

// Dobrando um valor
keep quantity = 3;
quantity = quantity * 10;
say(quantity);  // Exibe: 30

Divisão (/)

keep quotient = 100 / 4;
say(quotient);  // Exibe: 25

// Dividindo pela metade
keep half = 50;
half = half / 2;
say(half);  // Exibe: 25

Operações Combinadas

Você pode encadear múltiplas operações:

keep result = 10;
result = result + 5;   // 15
result = result * 2;   // 30
result = result - 10;  // 20
result = result / 5;   // 4
say(result);  // Exibe: 4

Exemplo Prático: Carrinho de Compras

keep cartTotal = 0;
cartTotal = cartTotal + 25;   // Adiciona item 1
cartTotal = cartTotal + 15;   // Adiciona item 2
cartTotal = cartTotal + 10;   // Adiciona item 3
say(cartTotal);  // Exibe: 50

🔗 Concatenação de Strings

Em Jech, você pode juntar (concatenar) strings usando o operador +. Isso é muito útil para construir mensagens dinâmicas.

Concatenação Básica

// Juntando duas strings literais
say("Hello" + "World");  // Exibe: HelloWorld

// Com espaço
say("Hello" + " " + "World");  // Exibe: Hello World

Concatenação com Variáveis

keep firstName = "João";
keep lastName = "Lucas";
keep fullName = firstName + " " + lastName;
say(fullName);  // Exibe: João Lucas

Misturando Variáveis e Literais

keep greeting = "Hello";
say(greeting + " World!");  // Exibe: Hello World!

keep username = "joaoluke";
keep message = "User: " + username + "!";
say(message);  // Exibe: User: joaoluke!

Exemplo Prático: Construindo Mensagens

keep status = "active";
keep message = "User is " + status;
say(message);  // Exibe: User is active

keep step1 = "The";
keep step2 = step1 + " quick";
keep step3 = step2 + " brown";
keep step4 = step3 + " fox";
say(step4);  // Exibe: The quick brown fox
⚠️ Atenção: Concatenação de strings com + é diferente de adição numérica! "10" + "20" resulta em "1020" (string), enquanto 10 + 20 resulta em 30 (número).

🔀 Condicionais - Tomando Decisões com when/else

Condicionais permitem que seu programa tome decisões e execute diferentes códigos baseado em condições. Em Jech, usamos when (quando) para criar estruturas condicionais.

Operadores de Comparação

Antes de usar condicionais, você precisa conhecer os operadores de comparação:

// Igualdade
x == y    // Igual a
x != y    // Diferente de

// Comparação numérica
x > y     // Maior que
x < y     // Menor que
x >= y    // Maior ou igual a
x <= y    // Menor ou igual a

when com Booleanos

A forma mais simples de condicional usa valores booleanos diretamente:

// Sempre executa (true)
when (true) {
    say("Isso sempre executa");
}

// Nunca executa (false)
when (false) {
    say("Isso nunca executa");
}

// Com variável booleana
keep showMessage = true;
when (showMessage) {
    say("Mensagem visível!");
}

when com Comparações

Você pode usar operadores de comparação para criar condições mais complexas:

keep age = 25;

when (age > 18) {
    say("Você é adulto");
}

keep temperature = 15;

when (temperature < 20) {
    say("Está frio lá fora");
}

keep score = 100;

when (score == 100) {
    say("Pontuação perfeita!");
}

when com Strings

Você também pode comparar strings usando ==:

keep color = "blue";

when (color == "blue") {
    say("A cor é azul");
}

when/else - Lidando com Ambos os Casos

Use else para executar código quando a condição é falsa. Isso cria uma estrutura "se-senão": 

keep age = 16;

when (age >= 18) {
    say("Você pode votar");
}
else {
    say("Muito jovem para votar");
}

// Outro exemplo
keep isLoggedIn = false;

when (isLoggedIn) {
    say("Bem-vindo de volta!");
}
else {
    say("Por favor, faça login");
}

Múltiplas Condições (else when)

Para testar várias condições em sequência, use else when:

keep grade = 85;

when (grade >= 90) {
    say("Excelente! Nota A");
}
else when (grade >= 80) {
    say("Muito bom! Nota B");
}
else when (grade >= 70) {
    say("Bom! Nota C");
}
else when (grade >= 60) {
    say("Passou! Nota D");
}
else {
    say("Reprovado");
}

Exemplo Prático: Sistema de Autenticação

keep username = "admin";
keep isAuthenticated = false;

say("=== Sistema de Login ===");

when (username == "admin") {
    say("Usuário válido");
    isAuthenticated = true;
}
else {
    say("Usuário desconhecido");
}

when (isAuthenticated) {
    say("Bem-vindo ao sistema!");
}
else {
    say("Faça login primeiro");
}

Exemplo Prático: Verificação de Estoque

keep inventory = 5;

when (inventory > 10) {
    say("Estoque alto");
}
else when (inventory > 0) {
    say("Estoque baixo");
}
else {
    say("Sem estoque");
}

📋 Arrays - Trabalhando com Listas

Arrays (ou listas) são coleções ordenadas de valores. Eles permitem armazenar múltiplos valores em uma única variável e acessá-los por índice.

Criando Arrays

Arrays são criados usando colchetes [] com valores separados por vírgula:

// Array de números
keep numbers = [1, 2, 3, 4, 5];

// Array de strings
keep fruits = ["maçã", "banana", "laranja"];

// Array vazio
			
📊 Trabalhando com Arrays

			

				Arrays em Jech são indexados em zero e dinâmicos. Você pode acessar, modificar e
				percorrer listas de valores facilmente.
			


			
Acessando Elementos

			
keep fruits = ["Maçã", "Banana", "Uva"];

say(fruits[0]);  // Exibe: Maçã
say(fruits[1]);  // Exibe: Banana
say(fruits[2]);  // Exibe: Uva


			
Modificando Elementos

			
keep list = [10, 20, 30];
list[1] = 99;
say(list);  // Exibe: [10, 99, 30]


			
Tamanho do Array

			
Use o método .size() para obter a quantidade de elementos:

			
keep tags = ["web", "dev", "code", "jech"];
say(tags.size());  // Exibe: 4


			
Exemplo Prático: Lista de Compras

			
keep todo = ["Estudar Jech", "Fazer café", "Codar"];
say("Total de tarefas: " + todo.size());
say("Primeira tarefa: " + todo[0]);


			
Método map - Transformando Arrays

			

				O método map permite aplicar uma operação matemática a todos os elementos
				de um array de uma vez. É muito útil para transformações em massa.
			

			
keep numbers = [1, 2, 3, 4, 5];
say(numbers);  // Exibe: [1, 2, 3, 4, 5]

// Multiplicar cada elemento por 2
keep doubled = numbers.map(* 2);
say(doubled);  // Exibe: [2, 4, 6, 8, 10]

// Adicionar 10 a cada elemento
keep added = numbers.map(+ 10);
say(added);  // Exibe: [11, 12, 13, 14, 15]

// Dividir cada elemento por 2
keep halved = numbers.map(/ 2);
say(halved);  // Exibe: [0.5, 1, 1.5, 2, 2.5]

// Subtrair 1 de cada elemento
keep decreased = numbers.map(- 1);
say(decreased);  // Exibe: [0, 1, 2, 3, 4]


			
Exemplo Prático: Cálculo de Preços

			
keep prices = [100, 200, 300, 400];
say(prices);

// Aplicar 10% de imposto (multiplicar por 1.1)
keep withTax = prices.map(* 1.1);
say(withTax);  // [110, 220, 330, 440]

// Aplicar 20% de desconto (multiplicar por 0.8)
keep discounted = prices.map(* 0.8);
say(discounted);  // [80, 160, 240, 320]


			
Exemplo Prático: Ajuste de Notas

			
keep scores = [85, 90, 78, 92, 88];
say(scores);

// Curva: adicionar 5 pontos para todos
keep curved = scores.map(+ 5);
say(curved);  // [90, 95, 83, 97, 93]


			
🛠️ Funções - Organizando Código com do

			

				Funções permitem que você agrupe um bloco de código e o execute várias vezes.
				Em Jech, usamos a palavra-chave do para definir uma função.
			


			
Definindo uma Função

			
do sayHello() {
    say("Olá de dentro da função!");
}


			
Chamando uma Função

			
sayHello();  // Executa o código da função
sayHello();  // Pode ser chamada múltiplas vezes


			
Funções com Parâmetros

			
do greet(name) {
    say("Olá, " + name + "!");
}

greet("Alice");  // Exibe: Olá, Alice!
greet("Bob");    // Exibe: Olá, Bob!


			
Múltiplos Parâmetros

			
do add(a, b) {
    say(a + b);
}

add(5, 3);    // Exibe: 8
add(10, 20);  // Exibe: 30


			
Exemplo Prático: Calculadora de Área

			
do calculateArea(width, height) {
    keep area = width * height;
    say("A área é: " + area);
}

calculateArea(5, 10);  // Exibe: A área é: 50
calculateArea(7, 3);   // Exibe: A área é: 21


			

				💡 Dica: Funções ajudam a manter seu código limpo, organizado e evitam
				repetição de lógica.
			


			
Função com Retorno

			
Funções podem retornar valores usando return:

			
do double(n) {
    return n * 2;
}

keep res = double(10);
say(res);  // Exibe: 20


			
Exemplo Prático: Calculadora

			
do add(x, y) {
    return x + y;
}

do multiply(x, y) {
    return x * y;
}

keep sum = add(10, 5);
say(sum);  // Exibe: 15

keep product = multiply(4, 7);
say(product);  // Exibe: 28


			
🎯 Exemplos Práticos Completos


			
1. Sistema de Autenticação de Usuário

			
Um exemplo completo de sistema de login com verificação de credenciais:

			
// Dados do usuário
keep username = "admin";
keep isAuthenticated = false;
keep loginAttempts = 0;

say("=== Sistema de Login ===");
say(username);
say(isAuthenticated);

// Simular tentativa de login
loginAttempts = loginAttempts + 1;
say("Tentativa de login:");
say(loginAttempts);

// Verificar credenciais
when (username == "admin") {
    say("Usuário válido");
    isAuthenticated = true;
}
else {
    say("Usuário desconhecido");
}

// Verificar autenticação
when (isAuthenticated) {
    say("Bem-vindo ao sistema!");
}
else {
    say("Faça login primeiro");
}


			
2. Gerenciamento de Inventário

			
Sistema para controlar estoque de produtos:

			
keep productName = "Notebook";
keep stock = 15;
keep minStock = 10;
keep maxStock = 50;

say("=== Gerenciamento de Inventário ===");
say(productName);
say("Estoque atual:");
say(stock);

// Verificar níveis de estoque
when (stock < minStock) {
    say("ALERTA: Estoque baixo!");
}
else when (stock > maxStock) {
    say("AVISO: Estoque muito alto");
}
else {
    say("Estoque em nível adequado");
}

// Simular venda
stock = stock - 3;
say("Após venda:");
say(stock);


			
3. Sistema Bancário Simples

			
Gerenciamento de conta bancária com depósitos e saques:

			
keep accountHolder = "João Silva";
keep balance = 1000;
keep minBalance = 100;

say("=== Sistema Bancário ===");
say(accountHolder);
say("Saldo inicial:");
say(balance);

// Depósito
keep deposit = 500;
balance = balance + deposit;
say("Após depósito:");
say(balance);

// Tentativa de saque
keep withdrawal = 800;
keep newBalance = balance - withdrawal;

when (newBalance >= minBalance) {
    balance = newBalance;
    say("Saque aprovado");
    say(balance);
}
else {
    say("Saque negado - saldo insuficiente");
}


			
💡 Exemplos Práticos

			

				Aqui estão alguns exemplos completos que combinam vários conceitos da linguagem
				para resolver problemas reais.
			


			
1. Calculadora de Média Escolar

			
do calculateGrade(name, n1, n2, n3) {
    keep average = (n1 + n2 + n3) / 3;
    say("Aluno: " + name);
    say("Média: " + average);

    when (average >= 7) {
        say("Status: Aprovado! 🎉");
    }
    else {
        say("Status: Reprovado. Estude mais!");
    }
}

calculateGrade("João", 8, 7, 9);


			
2. Sistema de Bilheteria

			
do checkTicket(age, hasStudentCard) {
    keep price = 50;

    when (age < 12) {
        price = 20;
        say("Desconto infantil aplicado");
    }
    else when (hasStudentCard) {
        price = 25;
        say("Meia-entrada para estudante");
    }

    say("Valor a pagar: R$ " + price);
}

checkTicket(10, false);
checkTicket(25, true);


			
3. Carrinho de Compras com Taxa

			
keep products = [100, 250, 50];
keep subtotal = products[0] + products[1] + products[2];
keep tax = 0.1; // 10% de imposto

keep finalPrice = subtotal * (1 + tax);

say("Subtotal: R$ " + subtotal);
say("Total com impostos: R$ " + finalPrice);


			
4. Monitoramento de Temperatura

			
keep location = "Sala de Servidores";
keep temperature = 28;
keep minTemp = 18;
keep maxTemp = 25;

say("=== Monitor de Temperatura ===");
say(location);
say("Temperatura atual:");
say(temperature);

when (temperature > maxTemp) {
    say("ALERTA: Temperatura muito alta!");
    say("Ativar sistema de refrigeração");
}
else when (temperature < minTemp) {
    say("AVISO: Temperatura muito baixa");
}
else {
    say("Temperatura normal");
}


			
5. Calculadora de Pontuação de Quiz

			
keep studentName = "Ana";
keep score = 0;
keep totalQuestions = 5;

say("=== Quiz Jech ===");
say(studentName);

// Questão 1
keep answer1 = "keep";
when (answer1 == "keep") {
    score = score + 1;
}

// Questão 2
keep answer2 = "when";
when (answer2 == "when") {
    score = score + 1;
}

// Questão 3
keep answer3 = "say";
when (answer3 == "say") {
    score = score + 1;
}

// Questão 4
keep answer4 = "do";
when (answer4 == "do") {
    score = score + 1;
}

// Questão 5
keep answer5 = "return";
when (answer5 == "return") {
    score = score + 1;
}

say("Pontuação final:");
say(score);

// Avaliar desempenho
keep percentage = (score / totalQuestions) * 100;
say("Porcentagem: " + percentage + "%");

when (percentage >= 80) {
    say("Excelente!");
}
else when (percentage >= 60) {
    say("Bom trabalho!");
}
else {
    say("Continue estudando");
}
